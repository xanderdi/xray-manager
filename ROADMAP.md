# xray-manager Roadmap

This roadmap describes the planned development direction of `xray-manager`.

Plans may change as the project evolves.

## v0.2.0 — Installation & foundation

* One-command installation
* Automatic Xray Core installation
* Xray Core download from official releases
* Automatic dependency installation
* Safe upgrade workflow
* Backup and rollback improvements
* Prepare a stable backend for future GUI integration

## v0.3.0 — Desktop GUI & tray

* System tray application
* Quick switching between `OFF`, `SOCKS`, `SPLIT`, and `FULL`
* Current mode and Xray status indication
* Basic connection management
* Keep the existing CLI fully usable without GUI

## v0.4.0 — Routing management

* User-friendly SPLIT routing configuration
* Manage bypass and proxy rules without manually editing configuration files
* Domain and network rules
* Import/export routing rules
* GUI integration for routing configuration

## v0.5.0 — Protocols & profiles

* Multiple connection profiles
* Protocol selection in CLI and GUI
* Additional Xray-supported protocols and transports
* Easier connection import and management

## Long-term

* Keep CLI and GUI as separate layers
* Preserve CLI operation on headless systems
* Manager update mechanism
* Improve diagnostics and health checks
* Automated installation and integration tests
* Debian package
* Documentation for advanced routing scenarios
